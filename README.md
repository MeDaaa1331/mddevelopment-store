## 🛠️ Free FiveM Developer Tools Suite (15 Utilities)

MD Development provides 15 free, browser-based utilities for GTA V and FiveM developers with zero latency, zero downloads, and instant code export at [**mddevelopment.store/devtools**](https://www.mddevelopment.store/devtools):

1. **[Vehicle Handling Editor](https://www.mddevelopment.store/devtools)**: Interactive visualizer and editor for GTA V `handling.meta` files. Calculate mass, drivetrain bias, traction curves, suspension stiffness, and anti-roll bars with one-click XML export.
2. **[Locales & Translation Generator](https://www.mddevelopment.store/devtools)**: Translate and format script language files between English, Czech, German, French, Spanish, Italian, and Polish for ox_lib, ESX, and QBCore.
3. **[Flags & YTYP Archetype Generator](https://www.mddevelopment.store/devtools)**: Calculate 32-bit bitmask integers and binary flags for GTA V vehicle models, handling flags, damage flags, and map YTYP archetypes.
4. **[Blip & Radar Designer](https://www.mddevelopment.store/devtools)**: Visual GTA V radar map blip builder with sprite search, RGB/palette color selector, and Lua snippet generation for ox_lib and native FiveM.
5. **[JSON to Lua / Table Formatter](https://www.mddevelopment.store/devtools)**: Convert JSON data into optimized Lua tables with syntax validation and indentation formatting.
6. **[Weapons & Ammo Configurator](https://www.mddevelopment.store/devtools)**: Interactive balancing tool for weapon damages, recoil, clip sizes, ammo types, and attachments for ox_inventory and qb-weapons.
7. **[Audio FX & Sound Explorer](https://www.mddevelopment.store/devtools)**: Searchable directory of GTA V frontend audio sound names, sound sets, and `PlaySoundFrontend` triggers.
8. **[Ped & Prop Spawner](https://www.mddevelopment.store/devtools)**: Database of GTA V ped models and prop hashes with target interaction boilerplate generator.
9. **[Coords & PolyZone Generator](https://www.mddevelopment.store/devtools)**: Format in-game Vector3, Vector4, and PolyZone box coordinates for ox_target, qb-target, and ESX zones.
10. **[Discord Webhook Embed Builder](https://www.mddevelopment.store/devtools)**: Custom Discord embed designer with ready-to-paste FiveM Lua backend webhook code.
11. **[GTA Controls & Keybind Lookup](https://www.mddevelopment.store/devtools)**: Comprehensive lookup for FiveM control IDs, key mapping names, and game input indices.
12. **[fxmanifest.lua Generator](https://www.mddevelopment.store/devtools)**: Resource manifest generator with Lua 5.4, UI pages, and escrow metadata declarations.
13. **[GTA V Hash Converter](https://www.mddevelopment.store/devtools)**: Instant Joaat (`GetHashKey`) string-to-hash and hex-to-decimal converter for GTA V assets.
14. **[Animation & Scenario Explorer](https://www.mddevelopment.store/devtools)**: Complete index of GTA V animation dictionaries, task animations, and scenario names.
15. **[Color & HEX Palette Picker](https://www.mddevelopment.store/devtools)**: GTA V vehicle paint index reference, RGB color codes, and HEX palette generator.
